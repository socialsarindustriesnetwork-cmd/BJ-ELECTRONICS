# Caravan reference research

Source reviewed: https://caravan.com.bd/

The BJ Electronics storefront should retain its own branding, data model, product content, and transactional workflows. The reference is used only for marketplace information architecture and interaction patterns:

- utility bar and support-first header;
- prominent catalog search;
- high-density category navigation;
- hero area paired with category shortcuts and promotional cards;
- flash-sale merchandising;
- category collections, featured brands, and trust/service panels;
- strong Bangladesh-specific delivery and payment messaging;
- responsive mobile navigation.

No Caravan branding, proprietary copy, product photography, or source code is copied.
