# Caravan-inspired BJ Electronics marketplace implementation

The implementation keeps BJ Electronics branding and production commerce behavior while adopting a denser marketplace layout inspired by the reference site's information architecture.

## Planned modules

- support-first utility bar;
- catalog search with category selector;
- category rail and promotional hero;
- flash sale merchandising;
- featured categories and product collections;
- brand discovery strip;
- Bangladesh delivery, warranty, returns, and payment trust blocks;
- responsive mobile navigation and compact commerce controls.

## Production constraints

- product content remains database-driven;
- cart, checkout, order, inventory, and realtime APIs remain authoritative;
- no third-party brand assets or proprietary source code are copied;
- canonical production domain remains `https://www.bjelectronics.shop`.
